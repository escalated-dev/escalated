<h1 align="center">Escalated</h1>

<p align="center">
  Tickets de soporte, integrados en tu aplicación.<br>
  Un helpdesk de código abierto con SLA, reglas de escalado, una bandeja de entrada para agentes y un portal de clientes.
</p>

## Inicio rápido

Este paquete es el frontend compartido de Vue 3 + Inertia. No lo instalas por separado: añade el paquete de tu backend y este trae la interfaz consigo.
