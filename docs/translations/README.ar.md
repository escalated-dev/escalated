<h1 align="center">Escalated</h1>

<p align="center">
  تذاكر دعم مدمجة في تطبيقك.<br>
  مكتب مساعدة مفتوح المصدر يتضمن اتفاقيات مستوى الخدمة (SLA) وقواعد التصعيد وصندوق وارد للوكلاء وبوابة للعملاء.
</p>
