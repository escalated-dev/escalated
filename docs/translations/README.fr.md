<h1 align="center">Escalated</h1>

<p align="center">
  Des tickets de support, intégrés à votre application.<br>
  Un helpdesk open source avec SLA, règles d'escalade, boîte de réception pour les agents et portail client.
</p>

  <tr>

      </picture>
    </td>
  </tr>
  <tr>
    <td width="60%">
      <picture>
        <source media="(prefers-color-scheme: dark)" srcset="../assets/readme/dashboard-dark.png">

## Démarrage rapide

Ce paquet est le frontend Vue 3 + Inertia partagé. Vous ne l'installez pas seul : ajoutez le paquet de votre backend, il apporte cette interface avec lui.
