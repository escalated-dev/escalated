<h1 align="center">Escalated</h1>

<p align="center">
  Supporttickets, ingebouwd in je app.<br>
  Een open-source helpdesk met SLA's, escalatieregels, een inbox voor medewerkers en een klantportaal.
</p>

## Snel aan de slag

Dit pakket is de gedeelde Vue 3 + Inertia-frontend. Je installeert het niet los: voeg het pakket voor je backend toe en deze interface komt mee.
