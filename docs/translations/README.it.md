<h1 align="center">Escalated</h1>

<p align="center">
  Ticket di supporto, integrati nella tua app.<br>
  Un helpdesk open source con SLA, regole di escalation, una inbox per gli operatori e un portale clienti.
</p>

## Avvio rapido

Questo pacchetto è il frontend condiviso Vue 3 + Inertia. Non lo installi da solo: aggiungi il pacchetto per il tuo backend e porterà con sé questa interfaccia.
