<h1 align="center">Escalated</h1>

<p align="center">
  アプリに組み込める、サポートチケット。<br>
  SLA、エスカレーションルール、エージェント用受信トレイ、顧客ポータルを備えたオープンソースのヘルプデスクです。
</p>

<table>
  <tr>
    <td width="40%">
      <h3>エージェントが一日中作業できる受信トレイ</h3>

    <td width="60%">
      <picture>

      </picture>
    </td>
  </tr>
  <tr>
    <td width="60%">
      <picture>
        <source media="(prefers-color-scheme: dark)" srcset="../assets/readme/dashboard-dark.png">

    <td width="40%">
      <h3>目に見える SLA とエスカレーションルール</h3>
      優先度ごとに応答と解決の目標を設定し、遅れたら自動でエスカレーションし、違反はレポートページで追跡できます。

## 機能一覧

<table>
<tr>
<td width="33%" valign="top">

**エージェントワークスペース**
- 保存済みビュー付きのフィルタ可能なキュー
- クイックフィルタ: 自分の担当、未割り当て、緊急、SLA
- 一括操作とマクロ
- 内部メモとピン留めメモ
- 返信エディタ内の定型返信
- キーボードショートカットとコマンドパレット

</td>
<td width="33%" valign="top">

**チケットツール**
- 返信を新しいチケットに分割
- プリセットと自動再開付きのスヌーズ
- 気になるチケットをフォロー
- ドラッグ＆ドロップでファイルを添付
- すべてを記録するアクティビティタイムライン

</td>
<td width="33%" valign="top">

**SLA とエスカレーション**
- 警告と違反を表示する SLA カウントダウン
- SLA ポリシーの管理
- エスカレーションルールビルダー
- 部署とタグ

</td>
</tr>
<tr>
<td width="33%" valign="top">

**顧客ポータル**
- フィルタと検索付きのチケット一覧
- 添付ファイル対応の新規チケットフォーム
- 返信スレッドとステータス追跡
- コメント付きの CSAT 評価
- ナレッジベース (オン/オフ切り替え可)

</td>
<td width="33%" valign="top">

**リアルタイム**
- Pusher、Reverb、Soketi によるライブ更新
- 自動ポーリングへのフォールバック
- 同じチケットを見ている他のユーザーを表示
- 返信中の衝突警告

</td>
<td width="33%" valign="top">

**アプリになじむ設計**
- 既存のレイアウト内で描画
- 色、角丸、フォントのテーマトークン
- 管理画面を自分の管理パネルに埋め込み可能
- どのサイトにも置けるサポートウィジェット
- ページとサイドバーウィジェット用のプラグイン

</td>
</tr>
</table>
