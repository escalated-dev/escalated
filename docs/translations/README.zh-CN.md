<h1 align="center">Escalated</h1>

<p align="center">
  支持工单，直接内置到你的应用中。<br>
  一个开源帮助台，提供 SLA、升级规则、客服收件箱和客户门户。
</p>

    <td width="60%">
      <picture>

## 功能列表

<table>
<tr>
<td width="33%" valign="top">

**客服工作区**
- 可筛选的队列与已保存视图
- 快速筛选：我的、未分配、紧急、SLA
- 批量操作和宏
- 内部备注和置顶备注
- 编辑器中的预设回复
- 键盘快捷键和命令面板

</td>
<td width="33%" valign="top">

**工单工具**
- 将回复拆分为新工单
- 暂缓工单，支持预设时长并自动唤醒
- 关注你在意的工单
- 拖放上传附件
- 完整的活动时间线

</td>
<td width="33%" valign="top">

**SLA 和升级**
- 带警告和违规提示的 SLA 倒计时
- SLA 策略管理
- 升级规则构建器
- 部门和标签

</td>
</tr>
<tr>
<td width="33%" valign="top">

**客户门户**
- 带筛选和搜索的工单列表
- 支持附件的新建工单表单
- 回复线程和状态跟踪
- 带评论的 CSAT 评分
- 知识库，可开可关

</td>
<td width="33%" valign="top">

**实时**
- 通过 Pusher、Reverb 或 Soketi 实时更新
- 自动回退到轮询
- 查看还有谁在浏览同一工单
- 回复时的冲突提醒

</td>
<td width="33%" valign="top">

**融入你的应用**
- 在你自己的布局中渲染
- 颜色、圆角、字体的主题令牌
- 管理后台可嵌入你的管理面板
- 可放到任意网站的即用型支持小组件
- 用于页面和侧边栏小组件的插件

</td>
</tr>
</table>

## 快速开始

这个包是共享的 Vue 3 + Inertia 前端。你不需要单独安装它：为你的后端添加对应的包，这套界面会随之一起安装。
