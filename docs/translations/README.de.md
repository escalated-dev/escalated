<h1 align="center">Escalated</h1>

<p align="center">
  Support-Tickets, direkt in deine App eingebaut.<br>
  Ein Open-Source-Helpdesk mit SLAs, Eskalationsregeln, einem Agenten-Posteingang und einem Kundenportal.
</p>

## Was es kann

<table>
  <tr>
    <td width="40%">

    </td>
    <td width="60%">

      </picture>
    </td>
  </tr>
  <tr>
    <td width="60%">
      <picture>
        <source media="(prefers-color-scheme: dark)" srcset="../assets/readme/dashboard-dark.png">

    </td>
    <td width="40%">
      <h3>SLAs und Eskalationsregeln, die du sehen kannst</h3>

## Schnellstart

Dieses Paket ist das gemeinsame Vue 3 + Inertia-Frontend. Du installierst es nicht einzeln: Füge das Paket für dein Backend hinzu, und es bringt diese Oberfläche mit.
