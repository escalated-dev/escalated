<h1 align="center">Escalated</h1>

<p align="center">
  Tickets de suporte, integrados ao seu app.<br>
  Um helpdesk de código aberto com SLAs, regras de escalonamento, uma caixa de entrada para agentes e um portal do cliente.
</p>

## Início rápido

Este pacote é o frontend compartilhado em Vue 3 + Inertia. Você não o instala sozinho: adicione o pacote do seu backend e ele traz esta interface junto.
